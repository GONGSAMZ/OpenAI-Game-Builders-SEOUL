# 선자 스토리 컷씬 이미지 시안 v1

선자의 특별 주문 성공 뒤 클릭할 때마다 공개할 5개 스토리 컷과 마지막 해금 일러스트 시안이다. 이미지 안에는 글자와 말풍선을 넣지 않았으며, 대사와 캡션은 Unity UI에서 표시한다. 내레이션 음성은 사용하지 않는다.

## 재생 순서

| 클릭 | 파일 | 장면 |
| --- | --- | --- |
| 1 | `sunja-story-01-winter-memory.png` | 젊은 선자와 남편이 겨울 거리에서 붕어빵을 나누고 새 녹색 천을 사 온 과거 |
| 2 | `sunja-story-02-stopped-sewing.png` | 남편이 떠난 뒤 같은 보랏빛 코트만 반복해서 수선하는 현재 |
| 3 | `sunja-story-03-matcha-awakening.png` | 녹차 붕어빵을 먹은 순간 오늘출발 말차붕이 깨어나는 전환점 |
| 4 | `sunja-story-04-new-stitch.png` | 새 녹색 천을 펼치고 추억 조각을 담는 주머니를 만드는 다음 날 |
| 5 | `sunja-story-05-walk-forward-v2.png` | 목도리 주머니에 사진을 넣고 동네 산책 모임의 손을 잡는 이후 이야기 |
| 해금 | `sunja-unlock-illustration-v2.png` | 만족한 선자, 녹차 붕어빵, 뒤에서 앞으로 날아가는 오늘출발 말차붕 |

`sunja-story-flow-preview-v2.png`는 위 여섯 장을 순서대로 검토하기 위한 미리보기다. 이름에 `v1`이 붙거나 버전 표기가 없는 이전 5컷·해금 이미지는 주머니 위치 수정 전 비교본이다.

## 기술 정보

- 형식: PNG, RGB
- 크기: 각 장 `1536 × 1024`
- 화면 비율: `3:2` 가로형
- 배경: 장면이 포함된 불투명 이미지
- 텍스트: 이미지에 포함하지 않음
- 오디오: 내레이션·대사 음성 없음. 선택적으로 컷 전환, 바삭, 천, 바느질, 해금 효과음만 사용한다.

## 아트 기준

- 선자 기준: `resources/character-art/new-customers/Sunja-uniform-v2-cutout.png`
- 말차붕 기준: `resources/character-art/bungeoppang-system/special-souls-v3.png`의 오른쪽 위 캐릭터
- 선자 고정 요소: 은빛 단발, 보랏빛 코트, 베이지 니트, 줄자와 수선 도구
- 말차붕 고정 요소: 각진 연형 붕어빵 몸, 녹색 속, 긴 녹색 스카프, 앞으로 향하는 자세
- 색 흐름: 빛바랜 보라색 과거 → 어두운 정지 상태 → 녹색 각성 → 밝은 아침
