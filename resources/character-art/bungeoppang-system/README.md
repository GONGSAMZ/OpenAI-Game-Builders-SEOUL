## v2 고정 규칙

- 조리 과정 9단계는 모두 같은 열린 붕어 틀 위에 둔다.
- 위에서 본 직교 시점, 머리는 오른쪽, 같은 카메라와 크기를 유지한다.
- 윗반죽 이후 붕어 외곽선과 비늘 위치를 고정한다.
- 속재료 창은 몸통의 25~35%이며 마지막 단계까지 계속 보인다.
- 완성품은 조리 중 붕어와 같은 쉐입을 사용하고 틀만 제거한다.
- 영혼은 붕어빵 70% / 개성 30%를 기준으로 한다. 모든 영혼에 붕어 머리·꼬리·비늘·구운 껍질을 남기고, 체형·지느러미·자세·속재료·소품만 다르게 한다.
- 기능성 글자와 상태 이름은 이미지에 굽지 않고 Unity UI로 표시한다.

### 조리 단계 프롬프트 요약

정확히 3×3 셀을 사용해 빈 틀, 아랫반죽, 팥 속재료, 윗반죽, 설익음, 말랑, 노릇, 바삭, 탐을 순서대로 배치했다. 모든 셀에 같은 열린 금속 틀을 유지하고, 3단계부터 팥 속재료가 배 중앙의 큰 창으로 계속 보이게 했다.

### 일반 맛 프롬프트 요약

팥, 슈크림, 초코, 크림치즈, 피자, 민트, 고구마, 녹차를 각각 한 칸에 배치했다. 각 칸의 왼쪽은 같은 틀 안 조리 상태, 오른쪽은 틀에서 꺼낸 완성품이다. 두 버전의 외곽선과 창은 같고 속재료의 색과 질감만 맛별로 바뀐다.

### 특별 영혼 프롬프트 요약

정현은 세로형 대장 붕어, 하진은 필름처럼 이어지는 잎 지느러미를 가진 긴 곡선형 붕어, 미주는 넓은 피자 붕어, 선자는 각진 연형 붕어, 건우는 낮고 둥근 초코 붕어, 태수는 긴 포옹 지느러미의 치즈 붕어, 나리는 낮고 단단한 고구마 붕어, 준호는 작고 튀는 팥 붕어로 구성했다. 서로 다른 체형을 사용하지만 모두 물고기 머리·꼬리·비늘·구운 껍질을 유지한다.

## 사용 전 처리

이 파일은 **팀 검토용 콘셉트**다. 승인 후에는 다음 처리가 필요하다.

1. 셀을 개별 PNG 또는 레이어 에셋으로 분리한다.
2. 조리 에셋의 캔버스, 크기와 `bottom-center` 기준점을 맞춘다.
3. 틀, 붕어 껍질, 속재료 창, 굽기 표면과 효과를 분리한다.
4. 영혼 8종은 공통 바닥선만 맞추고 캐릭터별 피벗과 충돌 영역을 정한다.
5. Unity에서 실제 조리 크기와 1920×1080 WebGL 화면을 검수한다.
