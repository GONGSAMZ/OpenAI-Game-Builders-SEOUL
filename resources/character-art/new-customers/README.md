# 신규 손님 5명 이미지 후보

선자, 건우, 태수, 나리, 준호의 캐릭터 시트에 들어갈 팀 공유용 이미지다. 2026-08-16에 OpenAI 이미지 생성 도구로 만들고, 기존 정현·하영·미주 시트와 가까워지도록 정면 시점으로 다시 생성했다.

전체 비교 이미지는 `new-customers-contact-sheet.png`다.

## 공통 생성 지시

- 따뜻한 겨울 수채화·옅은 과슈, 매트한 종이 질감, 얇고 부드러운 갈색 외곽선
- 기존 3명처럼 큰 머리와 단순화한 전신 비율, 과도한 사실 묘사와 광택 제외
- 얼굴, 코, 턱, 양쪽 어깨, 몸통, 골반과 발끝이 관객을 향하는 거의 완전한 정면
- 옆모습과 3/4 시점 금지, 양눈·양귀·양팔·양발이 보이게 구성
- 왼쪽부터 기본, 기쁨, 실망의 3표정
- 세 칸의 카메라, 자세, 캐릭터 크기, 눈높이와 바닥선을 고정하고 표정을 중심으로 변화
- 캐릭터별 복장, 대표 소품과 포인트 색은 `docs/07_CUSTOMER_CHARACTER_SHEETS.md`의 핵심 실루엣을 따름
- 글자, 로고, 워터마크, 그림자 무대와 배경 소품 제외

## 후처리와 검증

- 생성 원본의 밝은 체크무늬 배경은 `tools/remove_checkerboard_background.py`로 제거했다.
- PNG 5개 모두 1536×1024, RGBA, 알파 범위 0–255를 확인했다.
- Figma의 04–08 캐릭터 시트에 이미지를 배치하고 실제 프레임 스크린샷으로 표시 상태를 검수했다.
- 팀 공유본을 `resources/` 아래에 둔 이유는 루트의 소문자 `assets/`가 Windows에서 Unity용 `/Assets/` 제외 규칙과 충돌해 Git에 잡히지 않기 때문이다.

이 파일들은 **팀 검토용 후보**다. 팀 승인과 Unity·WebGL 화면 검수를 마치기 전에는 기존 게임 자산을 덮어쓰지 않는다.
