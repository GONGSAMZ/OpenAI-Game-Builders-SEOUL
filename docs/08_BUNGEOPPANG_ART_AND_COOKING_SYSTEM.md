## 1. 핵심 결정

조리 중에는 붕어빵이 항상 열린 붕어 틀 위에 있다. 속재료는 윗반죽을 올린 뒤에도 배 중앙의 큰 창을 통해 보여야 하며, 조리 중 붕어빵과 틀에서 꺼낸 완성품은 같은 외곽선을 사용한다.

```text
Mold Base
+ Bun Shell (fixed silhouette)
+ Filling Window (8 flavors)
+ Bake Surface (5 result states)
+ Steam / Sparkle / Smoke
```

영혼은 단순히 같은 붕어 몸체에 눈과 팔만 붙인 복사본이 아니다. 다만 모든 정답 영혼은 먼저 '살아난 붕어빵'으로 읽혀야 하며, 공통 정체성과 개성의 비율을 '붕어빵 70% / 캐릭터 변형 30%'로 유지한다.

- 틀: 9개 조리 단계에서 같은 형태, 위치, 방향과 카메라를 유지한다.
- 붕어 몸체: 윗반죽 이후 외곽선과 비늘 위치를 고정한다.
- 맛: 몸통 면적의 약 25~35%를 차지하는 실제 속재료 창으로 구분한다.
- 굽기: 같은 쉐입에서 껍질 명도, 가장자리, 균열, 김과 연기만 바꾼다.
- 완성품: 틀만 제거하며 붕어 외곽선과 속재료 창의 위치·크기는 바꾸지 않는다.
- 영혼: 붕어 머리·꼬리·비늘·구운 껍질을 반드시 유지한다. 체형은 20~30% 범위에서 바꾸고 지느러미·자세·속재료·소품으로 성격을 구분한다.

## 2. 조리 상태 9단계

| 순서 | 표시 이름 | 권장 상태 이름 | 결과 | 시각 단서 |
| --- | --- | --- | --- | --- |
| 1 | 빈 틀 | `Mold.Empty` | 조리 전 | 짙은 청회색의 열린 붕어 틀 |
| 2 | 아랫반죽 | `Batter.Bottom` | 진행 중 | 중앙에 넓은 홈을 남긴 연한 반죽 |
| 3 | 속 넣기 | `Filling.Visible` | 진행 중 | 배 중앙에 크게 드러난 실제 속재료 |
| 4 | 윗반죽 | `Batter.TopWithWindow` | 진행 중 | 속 주위만 덮고 배 중앙 창은 열어 둠 |
| 5 | 설익음 | `Bake.Undercooked` | 실패 | 창백하고 젖은 껍질, 속재료 창 유지 |
| 6 | 말랑 | `Bake.Soft` | 정상 1 | 연한 금색, 둥근 가장자리, 창 유지 |
| 7 | 노릇 | `Bake.Golden` | 정상 2 | 균일한 황금갈색, 창 유지 |
| 8 | 바삭 | `Bake.Crisp` | 정상 3 | 짙은 호박색과 선명한 가장자리, 창 유지 |
| 9 | 탐 | `Bake.Burnt` | 실패 | 검은 균열, 탄 속재료와 회색 연기 |

고정 규칙은 다음과 같다.

- 9칸 모두 같은 열린 붕어 틀을 보여 준다.
- 4~9단계의 붕어 외곽선은 완전히 동일하다.
- 속재료 창은 3단계부터 마지막까지 작아지거나 사라지지 않는다.
- `말랑`, `노릇`, `바삭`은 정상 결과이며 `설익음`, `탐`에서는 영혼이 나타나지 않는다.

## 3. 일반 맛 8종

작은 꼬리 도장이나 보조색만으로 맛을 표시하지 않는다. 플레이어가 작은 화면에서도 속재료의 색과 질감만 보고 맛을 구분할 수 있어야 한다.

| 맛 | 배 중앙 속재료 창 | 주 식별색 |
| --- | --- | --- |
| 팥 | 굵은 팥알이 보이는 팥소 | 버건디 |
| 슈크림 | 광택 있는 크림 소용돌이 | 크림 노랑 |
| 초코 | 가나슈와 초콜릿 조각 | 짙은 코코아 |
| 크림치즈 | 흰 치즈 덩어리와 부드러운 크림 | 아이보리 |
| 피자 | 토마토소스, 치즈, 옥수수와 작은 토핑 | 토마토 주황 |
| 민트 | 민트 크림과 초코칩 | 저채도 민트 |
| 고구마 | 보라색 앙금과 금색 고구마 조각 | 자주색과 금색 |
| 녹차 | 차 입자가 보이는 진한 말차 페이스트 | 말차색 |

Figma 일반 맛 시트의 각 칸은 `왼쪽: 같은 틀 안의 조리 상태 / 오른쪽: 틀에서 꺼낸 완성품`으로 구성한다. 두 버전의 외곽선, 머리 방향, 비늘 위치와 속재료 창이 일치해야 한다.

주문 아이콘과 속재료 창은 같은 색·재료 문법을 공유하지만, 조리 화면의 1차 식별 수단은 항상 실제 속재료 창이다.

## 4. 특별 영혼 8종

| 손님 | 조건 | 붕어빵 안에서의 개성 변형 | 반대 역할 |
| --- | --- | --- | --- |
| 정현 | 슈크림 + 바삭 | 세로형 대장 붕어, 시계 배지와 넥타이 | 자기 시간을 지키는 추진력 |
| 하진 | 민트 + 말랑 | 긴 곡선형 붕어, 필름처럼 이어지는 잎 지느러미와 나침반 | 정해진 공부 대본 밖에서 자기 장면을 선택하는 호기심 |
| 미주 | 피자 + 바삭 | 넓은 체형의 붕어, 토핑 능선과 메가폰 지느러미 | 취향을 먼저 말하는 표현력 |
| 선자 | 녹차 + 바삭 | 각진 연형 붕어, 말차 창과 긴 스카프 | 기억을 안고 전진하는 태도 |
| 건우 | 초코 + 말랑 | 낮고 둥근 붕어, 카드 지느러미와 초콜릿 장식 | 쓸모없는 장난을 즐기는 마음 |
| 태수 | 크림치즈 + 말랑 | 통통한 붕어, 길게 늘어난 포옹 지느러미 | 말과 포옹을 먼저 건네는 수용 |
| 나리 | 고구마 + 노릇 | 낮고 단단한 붕어, 보라색 등 능선과 닻 장식 | 한자리에 머무는 안정 |
| 준호 | 팥 + 말랑 | 작고 튀는 붕어, 팥 지느러미와 리본 | 서툰 첫 시도를 환영하는 응원 |

실루엣 검수에서는 색을 모두 검게 만들었을 때도 8종이 구분되어야 하지만, 각 실루엣에 물고기 머리와 연결된 꼬리 지느러미가 남아 있어야 한다. 시계·피자·잎·집 같은 모티프가 붕어빵 몸체 자체를 대체하면 실패다.

각성 조건은 다음 세 조건을 모두 만족해야 한다.

```text
맛 일치 AND 굽기 구간 일치 AND 특별 주문 활성
```

## 5. PC 조리 UI/UX

Figma의 16:9 화면은 다음 구조를 사용한다.

- 상단: 무한 영업 일자, 시간, 가게명, 돈, 설정
- 왼쪽: 일반 주문과 마지막 특별 주문
- 가운데: 같은 붕어 틀에서 진행되는 9개 조리 상태와 속재료 창 규칙
- 오른쪽: 설익음부터 탐까지 5개 굽기 구간과 특별 조건 확인
- 하단: 반죽, 맛 8종과 집게 도구

실제 게임에서는 한 틀의 이미지가 단계에 따라 바뀌며, Figma의 9칸 보드는 비교와 구현 검수를 위한 상태표다.

연결성 규칙:

- 맛을 선택하면 주문 아이콘과 배 중앙 속재료 창이 같은 재료로 바뀐다.
- 조리 단계가 진행되어도 틀, 붕어 외곽선과 창 위치는 움직이지 않는다.
- 선택된 도구는 색뿐 아니라 두꺼운 테두리로도 표시한다.
- 조리 상태는 이름, 껍질 표면과 김·연기를 함께 사용한다.
- 특별 주문은 별도 카드 색과 테두리로 구분하되 기존 주문 영역 안에 둔다.
- PC 조작은 도구 선택 → 틀 클릭 → 완성품 드래그 흐름을 유지한다.

## 6. 필요한 제작 에셋

| 묶음 | 수량 | 비고 |
| --- | ---: | --- |
| 빈 붕어 틀 | 1 | 모든 조리 단계에서 같은 베이스 사용 |
| 공통 붕어 쉐입 | 1 | 윗반죽 이후 외곽선 고정 |
| 반죽·굽기 표면 | 7 | 아랫반죽, 윗반죽, 설익음, 말랑, 노릇, 바삭, 탐 |
| 속재료 창 | 8 | 몸통의 25~35%, 맛별 색과 질감 포함 |
| UI 맛 아이콘 | 8 | SVG 또는 편집 가능한 벡터 |
| 정답 영혼 스프라이트 | 8 | 서로 다른 독립 몸체와 실루엣 |
| 효과 | 최소 3 | 김, 성공 반짝임, 탄 연기 |
| UI 상태 | 1세트 | 기본, 선택, 사용 가능, 사용 불가, 경고 |

조리 에셋은 같은 캔버스, 카메라, 중심점과 `bottom-center` 기준점을 사용한다. 영혼은 몸 크기가 다르므로 공통 바닥선만 맞추고, 충돌 영역과 이펙트 기준점은 캐릭터별로 정한다.

## 7. 현재 코드에서 바꿔야 할 연결

1. `QualityStatus`를 `Undercooked / Soft / Golden / Crisp / Burnt`에 대응하도록 확장한다.
2. `FishBunState_proto`의 숫자 인덱스 로드를 역할 이름 기반으로 바꾼다.
3. 빈 틀을 음식 상태 시트에서 분리해 모든 단계의 고정 베이스로 사용한다.
4. `Bun Shell`, `Filling Window`, `Bake Surface`를 별도 렌더 레이어로 나눈다.
5. 맛 선택 시 주문 아이콘과 `Filling Window`가 같은 맛 데이터를 참조하도록 한다.
6. 완성품은 조리 중 최종 쉐입을 그대로 사용하고 틀 레이어만 숨긴다.
7. 특별 주문 성공 시 정답 영혼의 독립 스프라이트와 성공 효과를 생성한다.

## 8. 이번 디자인에 포함한 항목

- 같은 열린 틀 위의 3×3 조리 상태 9종
- 조리 내내 유지되는 큰 속재료 창
- 일반 맛 8종의 `틀 안 / 완성품` 비교 시트
- 붕어빵 70% / 개성 30% 규칙을 지킨 정답 영혼 8종
- 주문용 맛 아이콘과 속재료 창의 연결 규칙
- 김, 반짝임과 탄 연기
- 선택 도구와 특별 주문 표시
- PC 16:9 조리 화면
- Unity 레이어 구성과 상태 이름
- 작은 창과 WebGL에서 확인할 QA 기준
