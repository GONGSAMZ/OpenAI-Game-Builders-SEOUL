# 따끈따끈 붕어빵 기획서

## 게임 한 줄 소개

손님의 주문에 맞춰 붕어빵을 굽고 판매하며, 제한된 영업 시간 안에 수익을 만드는 2D 타이쿤 게임이다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | 따끈따끈 붕어빵 (Bungeoppang Tycoon) |
| 장르 | 2D 타이쿤 / 시간 관리 게임 |
| 개발 형태 | 1인 개발 |
| 개발 도구 | Unity, C# |
| 수업 | 2D프로그래밍 |
| 개발 기간 | 2025.05.04 – 2025.06.12 |

## 플레이어 목표

플레이어는 붕어빵 가게 주인이 되어 손님의 주문을 빠르고 정확하게 처리한다. 하루 영업을 마친 뒤 돈과 판매 결과를 확인하고, 정해진 날짜까지 좋은 결과를 만든다.

## 핵심 재미

- **순서 판단:** 반죽, 재료, 굽기 순서를 맞춘다.
- **시간 압박:** 손님이 기다리는 동안 화남 게이지가 올라간다.
- **정확한 전달:** 주문과 다른 붕어빵을 주면 불이익이 생긴다.
- **운영 결과:** 하루 동안 번 돈과 판매량이 엔딩에 영향을 준다.

## 기본 게임 흐름

```text
인트로 → 게임 시작 → 손님 주문 확인 → 붕어빵 조리 → 손님에게 전달
→ 영업 시간 종료 → 하루 정산 → 다음 날 또는 엔딩
```

## 플레이 규칙

### 붕어빵 만들기

1. 도구를 선택한다.
2. 틀에 반죽을 넣는다.
3. 주문에 맞는 재료를 넣는다.
4. 적절한 시간 동안 굽는다.
5. 완성된 붕어빵을 손님에게 드래그해서 전달한다.

### 손님과 주문

- 손님마다 원하는 붕어빵 종류가 있다.
- 손님은 기다리는 동안 화남 게이지가 올라간다.
- 올바른 주문을 전달하면 돈을 얻는다.
- 잘못 만들었거나 너무 오래 기다리게 하면 손님 만족도가 떨어진다.

### 하루 종료와 엔딩

- 하루의 영업 시간이 끝나면 그날의 결과를 확인한다.
- 다음 날에 다시 영업을 시작한다.
- 마지막 날에는 보유 금액과 게임 조건에 따라 엔딩을 보여 준다.

## 화면 구성

| 화면 | 역할 |
| --- | --- |
| 인트로 | 게임 시작과 기본 안내 |
| 게임 화면 | 주문, 돈, 시간, 조리 공간 표시 |
| 상점 | 재료 또는 게임 진행 요소 확인 |
| 하루 종료 | 하루 결과와 다음 날 진행 |
| 엔딩 | 최종 결과 표시 |
| 설정 | 소리 등 기본 옵션 조절 |

## 나중에 확장할 수 있는 요소

- 재료 종류와 손님 주문 추가
- 어려운 주문이나 복수 주문 추가
- 업그레이드: 조리 속도, 손님 인내심, 판매 가격
- 일차별 목표와 이벤트
- 최고 점수 또는 일일 기록 저장

## 기획 확인 기준

- 처음 플레이하는 사람이 주문 → 조리 → 전달 흐름을 이해할 수 있다.
- 성공과 실패의 이유를 화면에서 알 수 있다.
- 하루가 끝났을 때 돈과 판매 결과를 확인할 수 있다.
- 5일차까지 진행했을 때 엔딩을 확인할 수 있다.
