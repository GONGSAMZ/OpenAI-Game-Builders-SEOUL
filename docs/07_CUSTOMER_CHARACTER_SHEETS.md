## 1. 문서 역할

이 문서는 손님 8명의 캐릭터 시트를 게임 제작에 연결하기 위한 인덱스다.

- 이야기, 대사, 특별 주문 판정의 기준은 `06_CUSTOMER_STORY_AND_SOUL_DESIGN.md`다.
- 외형, 실루엣, 복장, 표정 방향과 팀 시각 검토는 위 Figma 파일을 기준으로 한다.
- Unity에서 사용하는 최종 파일은 캐릭터별 투명 PNG 스프라이트 시트다.
- Figma에 배치된 이미지는 팀 검토용 후보이며, 승인과 게임 화면 검수를 마치기 전에는 기존 Unity 자산을 덮어쓰지 않는다.

## 4. 공통 아트 방향

- 따뜻한 겨울 수채화와 옅은 과슈 질감을 사용한다.
- 경계선은 부드러운 갈색 또는 청회색으로 제한한다.
- 얼굴, 어깨, 몸통과 발이 화면 정면을 향하는 거의 완전한 정면 시점을 사용한다.
- 세 표정은 자세와 카메라를 고정하고 얼굴 표정만 달라 보이게 만든다.
- 캐릭터의 직업과 성격은 얼굴보다 실루엣과 대표 소품에서 먼저 읽혀야 한다.
- 사진 같은 광택, 숯가루 같은 검은 노이즈, 순검정 굵은 만화선은 사용하지 않는다.
- 캐릭터마다 포인트 색은 달라도 같은 종이 질감, 광원 방향, 명암 단계와 묘사 밀도를 유지한다.
- 표정이 바뀌어도 얼굴, 머리, 체형, 복장, 소품, 화면 점유율은 바뀌지 않는다.

| 표정 칸 | 512×1024, 정확히 3칸 |
| 표정 순서 | 기본 / 기쁨 / 실망 |
| 캐릭터 높이 | 최대 900px |
| 하단 기준선 | 아래에서 56px |

| Pivot | 가운데 `(0.5, 0.5)` |

## 6. 신규 5명 검토·적용 순서

1. Figma의 선자, 건우, 태수, 나리, 준호 v2 이미지를 두 팀원이 함께 검토한다.
2. 정면 카메라, 큰 머리 비율, 대표 소품, 포인트 색과 기존 3명과의 화풍 일관성을 승인한다.
3. 수정이 필요한 인물만 같은 기준으로 다시 생성하거나 부분 수정한다.
4. 세 표정의 눈높이, 몸 크기와 기준선을 최종 규격으로 패킹한다.
5. Unity에 후보로 추가한 뒤 실제 게임 화면 크기에서 검토한다.
6. WebGL 빌드에서도 투명 배경, 선명도, 표시 크기를 확인한다.
7. 최종 승인 전까지 기존 캐릭터 파일을 덮어쓰지 않는다.

## 7. 수정 규칙

- 이야기 설정을 바꾸면 먼저 `06_CUSTOMER_STORY_AND_SOUL_DESIGN.md`를 수정하고 Figma 문구를 맞춘다.
- 외형을 바꾸면 Figma에서 의견을 모은 뒤 이 문서의 핵심 실루엣 표를 맞춘다.
- 최종 PNG가 바뀌면 Figma 시트의 표정 3종 이미지와 하단 SOURCE 경로를 함께 갱신한다.
- GitHub Project에는 캐릭터별 작업 상태만 기록하고, 캐릭터 설정을 다시 복사하지 않는다.
- 생성 또는 편집에 사용한 도구, 날짜, 참조 이미지와 수정 이력은 캐릭터 이미지와 함께 기록한다.
