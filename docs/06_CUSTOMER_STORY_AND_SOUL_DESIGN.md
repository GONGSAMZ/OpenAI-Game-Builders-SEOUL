# 손님 이야기와 붕어빵 영혼 기획서

> 관련 이슈: [#3 손님 스토리와 특별 주문 시스템 구현](https://github.com/GONGSAMZ/OpenAI-Game-Builders-SEOUL/issues/3)  
> 문서 상태: 콘텐츠 초안 v0.1  
> 전제: 5일차 엔딩을 제거하고, 하나의 저장 데이터에서 영업일이 계속 이어지는 무한 운영 구조를 사용한다.

## 1. 콘텐츠 한 줄 정의

가게 문을 닫기 직전 찾아온 마지막 손님의 짧은 사연을 듣고, 그 사람에게 지금 필요한 반대 성격의 붕어빵 영혼을 만들어 건네는 이야기 수집 콘텐츠다.

이 콘텐츠의 목적은 붕어빵으로 손님의 인생 문제를 해결하는 것이 아니다. 손님이 평소와 다른 작은 행동을 한 번 선택하도록 등을 밀어 주는 따뜻한 판타지를 만든다.

## 2. 핵심 원칙

### 2.1 손님과 영혼의 관계

- 손님의 겉으로 보이는 성격과 숨은 고민을 먼저 설계한다.
- 정답 영혼은 손님과 무작위로 반대되는 존재가 아니라, 그 손님에게 지금 부족한 태도를 가진 존재여야 한다.
- 성공 후 손님은 갑자기 완전히 달라지지 않는다.
- 이야기 컷은 문제 해결이 아니라 `작은 첫 행동`에서 끝난다.
- 임상적인 질환을 짧은 음식 이야기로 치료하는 것처럼 표현하지 않는다.

### 2.2 특별 주문의 기본 규칙

- 하루에 특별 손님은 최대 한 명만 등장한다.
- 특별 손님에게는 붕어빵 하나만 건넬 수 있다.
- 정답은 맛과 굽기 상태의 조합으로 결정된다.
- 정답이 아니어도 만들어진 붕어빵 영혼은 영혼 도감에 등록된다.
- 실패한 손님은 일정 기간 뒤 다시 등장하며, 재도전할 때 단서를 하나 더 제공한다.
- 이야기를 해금한 손님은 특별 주문 후보에서 빠지지만 일반 손님으로 계속 등장한다.
- 8명의 이야기를 모두 해금해도 일반 영업과 도감 수집은 계속된다.

### 2.3 낮 대화 `말동무` 규칙

낮 영업 중 기다리고 있는 손님을 클릭하면 주문 처리와 별개로 짧게 말을 걸 수 있다. 이 대화는 손님의 성격과 특별 주문 사연을 미리 파악하는 탐색 수단이자, 이야기에 관심을 보인 플레이어에게 작은 운영 보상을 주는 기능이다.

- 손님마다 서로 다른 대화 주제 선택지 3개를 가진다.
- 한 번 말을 걸면 세 선택지 중 하나만 골라 답변을 듣고 대화를 종료한다.
- 같은 손님과는 게임 날짜 기준 하루에 한 번만 대화할 수 있다.
- 이미 들은 주제에는 도감과 선택지에 완료 표시를 붙이지만 다시 선택할 수 있다.
- 처음 듣는 주제를 완료하면 해당 내용이 손님 도감의 `들은 이야기`에 기록된다.
- 세 주제를 모두 들으면 그 손님의 성격과 사연을 파악한 것으로 처리하고 특별 주문 등장 조건 하나를 만족한다.
- 대화가 정상적으로 끝나면 해당 손님의 기다림·분노 게이지를 최대치의 10%p만큼 낮춘다. 이 수치는 플레이 테스트 후 조정할 수 있는 기획 기본값이다.
- 게이지는 0 아래로 내려가지 않으며, 하루 한 번 제한 때문에 같은 손님에게 감소 효과를 반복 적용할 수 없다.
- 대화창이 열린 동안 게임 시간과 다른 손님의 기다림 게이지를 잠시 멈춰 플레이어가 대사를 읽을 수 있게 한다.
- 완성된 붕어빵을 잡고 손님에게 드래그하는 중에는 전달 행동을 우선하며 대화창을 열지 않는다.
- 손님이 입장·퇴장 중이거나 이미 분노가 가득 차 떠나는 상태라면 대화할 수 없다.
- 그날 이미 대화한 손님에게는 말풍선 아이콘 대신 완료 표시를 보여 준다.

## 3. 무한 운영에서의 등장 구조

### 3.1 하루 흐름

```text
일반 영업
→ 마감 시간
→ 특별 손님 등장 여부 확인
→ 특별 주문 또는 바로 정산
→ 하루 정산
→ 상점·도감 확인
→ 다음 날 영업
```

### 3.2 특별 손님 후보 조건

다음 조건을 모두 만족한 손님만 그날의 특별 손님 후보가 된다.

1. 일반 손님으로 최소 3일 동안 등장해 낮 대화 주제 3개를 모두 완료했다.
2. 해당 손님의 정답 영혼에 필요한 맛이 상점에서 해금됐다.
3. 아직 손님 이야기가 해금되지 않았다.
4. 최근 특별 주문 실패 후 재등장 대기 기간이 끝났다.
5. 같은 날 다른 특별 손님이 선택되지 않았다.

### 3.3 추천 등장 규칙

- 첫 특별 주문은 시스템 학습을 위해 정현으로 고정한다.
- 첫 특별 주문은 정현의 낮 대화 주제 3개를 모두 들은 뒤 조건을 만족한 첫 마감에 발생시킨다. 정상 진행 기준으로 가장 빠른 시점은 3일차 마감이다.
- 이후에는 후보 중 `일반 방문 횟수가 많고 최근에 특별 손님으로 등장하지 않은 손님`을 우선한다.
- 정답 실패 시 2일 동안 쉬었다가 다시 후보가 된다.
- 재도전할 때는 기존 대사 뒤에 더 직접적인 힌트 한 줄을 추가한다.
- 후보가 없으면 특별 주문 없이 하루를 마감한다.
- 너무 오랫동안 이야기가 나오지 않는 상황을 막기 위해, 후보가 있을 때는 최소 3일 안에 특별 주문이 보장되게 한다.

## 4. 붕어빵 영혼 조합 규칙

### 4.1 맛은 영혼의 마음을 정한다

| 맛 | 영혼의 핵심 마음 | 성격 키워드 |
| --- | --- | --- |
| 팥 | 기본으로 돌아가기 | 소박함, 초심, 다시 시작 |
| 슈크림 | 자신의 즐거움 챙기기 | 자기 돌봄, 낙천, 여유 |
| 초코 | 놀이와 상상력 | 장난, 호기심, 몰입 |
| 크림치즈 | 감정을 부드럽게 표현하기 | 다정함, 솔직함, 포용 |
| 피자 | 원하는 것을 분명히 말하기 | 욕구, 표현, 자신감 |
| 민트 | 남과 다른 선택 받아들이기 | 개성, 변화, 엉뚱함 |
| 고구마 | 한곳에 머물며 관계 쌓기 | 뿌리, 인내, 안정 |
| 녹차 | 현재를 보고 새로 출발하기 | 맑음, 수용, 새 시작 |

### 4.2 굽기는 영혼의 행동 방식을 정한다

| 굽기 상태 | 행동 방식 | 성격 키워드 |
| --- | --- | --- |
| 말랑 | 서두르지 않고 유연하게 움직임 | 느긋함, 즉흥성, 부드러움 |
| 노릇 | 작은 행동을 꾸준히 이어 감 | 균형, 성실함, 지속성 |
| 바삭 | 망설이지 않고 행동하거나 말함 | 결단력, 직진, 선 긋기 |

`말랑`과 `바삭`은 조리 실패를 뜻하지 않는다. 특별 주문에서는 먹을 수 있는 굽기 범위를 세 구간으로 나눈다. 완전히 설익거나 탄 상태는 별도의 조리 실패로 처리하고 영혼을 만들지 않는다.

### 4.3 판정 결과

| 결과 | 조건 | 보상과 반응 |
| --- | --- | --- |
| 정확한 영혼 | 맛과 굽기 모두 일치 | 손님 이야기 컷, 손님 도감 전체 항목, 영혼 도감 등록 |
| 가까운 영혼 | 맛 또는 굽기 중 하나 일치 | 영혼 도감 등록, 손님의 짧은 반응과 추가 힌트 |
| 다른 영혼 | 둘 다 불일치 | 영혼 도감 등록, 일반 반응, 추후 재도전 |
| 조리 실패 | 설익음 또는 탐 | 영혼 미등장, 특별 손님의 위로 대사, 추후 재도전 |

## 6. 손님별 상세 기획

### 6.1 정현 — 일을 두고 가는 연습

#### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 나이·역할 | 32세, 중소기업 운영팀 회사원 |
| 기존 캐릭터 | 유지. 정장, 휴대폰, 메신저 가방을 사용한다. |
| 평소 선호 | 팥 붕어빵 |
| 겉성격 | 공손하고 성실하며 부탁받은 일을 빠르게 처리한다. |
| 숨은 고민 | 자신의 일이 아닌 부탁까지 거절하지 못해 퇴근 후의 시간이 계속 사라진다. |
| 필요한 태도 | 남은 일이 있어도 자기 시간을 선택하고 선을 긋는 태도 |

#### 평소 방문 대사

1. “팥 하나 주세요. 고르는 데 시간 쓰면 일이 더 밀려서요.”
2. “회사 단톡방은 퇴근 시간을 모르나 봐요.”
3. “제가 안 하면 아무도 안 할 것 같아서요.”

#### 낮 대화 선택지

| 플레이어 선택지 | 정현의 답변 | 파악할 수 있는 정보 |
| --- | --- | --- |
| “오늘은 몇 시에 퇴근하세요?” | “제가 정하는 건 아니죠. 일이 다 끝나야 가는 거니까요.” | 퇴근 시간을 스스로 정하지 못한다. |
| “휴대폰이 계속 울리네요.” | “제 일이 아닌 부탁도 많아요. 그래도 보고 나면 모른 척하기가 어렵더라고요.” | 다른 사람의 일까지 거절하지 못한다. |
| “퇴근하고 나면 뭘 좋아하세요?” | “글쎄요… 예전에는 있었던 것 같은데, 요즘은 집에 가면 바로 자서요.” | 자기 취향과 시간을 잃어버렸다. |

#### 특별 주문 대사

> “오늘도 제 일이 아닌 것까지 다 끝냈는데…”  
> “이상하게 제 하루는 하나도 안 남았네요.”  
> “하… 일은 끝이 없네요. 붕어빵은 아무거나 하나 주세요.”

#### 정답 영혼

| 항목 | 내용 |
| --- | --- |
| 이름 | 칼퇴대장 크림붕 |
| 조합 | 슈크림 + 바삭 |
| 성격 | 자기 즐거움을 먼저 챙기며, 끝낼 시간을 스스로 선언한다. |
| 대표 대사 | “끝나지 않는 일은 두고 가면 돼. 넌 끝날 시간이 있잖아.” |
| 반대 관계 | 모든 일을 책임지려는 정현 ↔ 자기 시간을 당당하게 지키는 영혼 |

#### 성공 이야기 컷

1. 정현이 붕어빵을 베어 무는 순간 회사 단체 채팅 알림이 울린다.
2. 크림붕이 휴대폰 화면 위에 올라가 알림을 몸으로 덮는다.
3. 정현은 잠시 고민하다 휴대폰을 뒤집어 놓는다.
4. 다음 날, 정현이 정시에 회사를 나오며 “내일 해도 되는 일은 내일의 제가 하겠죠.”라고 말한다.

#### 가까운 정답 힌트

> “조금 마음이 가벼워졌어요. 그런데 아직도 퇴근한다고 말할 용기가 부족한 것 같네요.”

#### 해금 후 일반 대사

> “오늘은 알림을 끄고 먹으려고요.”

### 6.2 하진 — 교과서 밖의 첫 장면

#### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 나이·역할 | 15세, 중학교 3학년 |
| 외형 키워드 | 단정한 네이비 중학교 교복, 포니테일, 작은 휴대용 카메라, 스토리보드 노트, 문제집이 가득한 학원 가방 |
| 평소 선호 | 슈크림 붕어빵 |
| 겉성격 | 조용히 주변을 관찰하고, 부모와 선생님이 정한 공부 일정도 불평 없이 지키는 모범생이다. |
| 숨은 고민 | 영화감독이 되고 싶지만 부모가 성적과 입시를 우선하며 영상 제작을 시간 낭비로 여긴다. 실망시킬까 두려워 직접 찍은 영상과 스토리보드를 문제집 사이에 숨긴다. |

## 8. 제작 범위 관리

손님 8명을 일주일 안에 구현하려면 모든 이야기를 서로 다른 고급 컷신으로 제작하면 안 된다.

### 권장 재사용 구조

- 특별 주문 대화 패널 1종을 모든 손님이 공유한다.
- 낮 대화 선택지 패널 1종과 `대화 가능 / 오늘 대화 완료` 아이콘을 모든 손님이 공유한다.
- 이야기 컷은 손님당 3~4컷으로 제한한다.
- 배경은 회사, 학교, 집·동네, 가게의 공통 배경을 재사용한다.
- 손님 기본 표정은 `평상 / 기쁨 / 실망` 3종을 공통 규격으로 맞춘다.
- 정답 영혼 8종은 '붕어빵 70% / 개성 30%'를 지킨다. 붕어 머리·꼬리·비늘·구운 껍질은 공통 정체성으로 유지하고, 손님의 결핍과 반대 역할이 드러나는 체형·지느러미·자세·속재료·소품을 다르게 제작한다.
- 나머지 맛·굽기 조합은 8종 정답 영혼의 몸체를 새로 복제하지 않는다. 도감에서는 맛 아이콘, 굽기 표면, 색과 짧은 성격 설명으로 기록해 일주일 제작 범위를 지킨다.
- 영혼 8종은 공통 바닥선과 렌더 크기 범위를 맞춘다. 키·폭·지느러미·방향·소품은 다르게 하되, 사물이나 다른 음식이 붕어빵 몸체를 대체하지 않게 한다.
- 대사는 한 화면에 최대 2문장만 보여 준다.


`talkedCustomerIdsToday`는 새 영업일을 시작할 때 비운다. 낮 영업 중 저장하고 다시 접속하는 경우에는 같은 날 대화 보상을 반복해서 받지 못하도록 현재 목록을 저장 데이터에 포함한다.
