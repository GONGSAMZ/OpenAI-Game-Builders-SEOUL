# 손님 이야기와 붕어빵 영혼 기획서

> 관련 이슈: [#3 손님 스토리와 특별 주문 시스템 구현](https://github.com/GONGSAMZ/OpenAI-Game-Builders-SEOUL/issues/3)  
> 문서 상태: 콘텐츠 초안 v0.1  
> 전제: 5일차 엔딩을 제거하고, 하나의 저장 데이터에서 영업일이 계속 이어지는 무한 운영 구조를 사용한다.

## 1. 콘텐츠 한 줄 정의

가게 문을 닫기 직전 찾아온 마지막 손님의 짧은 사연을 듣고, 그 사람에게 지금 필요한 반대 성격의 붕어빵 영혼을 만들어 건네는 이야기 수집 콘텐츠다.

이 콘텐츠의 목적은 붕어빵으로 손님의 인생 문제를 해결하는 것이 아니다. 손님이 평소와 다른 작은 행동을 한 번 선택하도록 등을 밀어 주는 따뜻한 판타지를 만든다.

## 2. 핵심 원칙

### 2.1 손님과 영혼의 관계

- 손님의 겉으로 보이는 성격과 숨은 고민을 먼저 설계한다.
- 정답 영혼은 손님과 무작위로 반대되는 존재가 아니라, 그 손님에게 지금 부족한 태도를 가진 존재여야 한다.
- 성공 후 손님은 갑자기 완전히 달라지지 않는다.
- 이야기 컷은 문제 해결이 아니라 `작은 첫 행동`에서 끝난다.
- 임상적인 질환을 짧은 음식 이야기로 치료하는 것처럼 표현하지 않는다.

### 2.2 특별 주문의 기본 규칙

- 하루에 특별 손님은 최대 한 명만 등장한다.
- 특별 손님에게는 붕어빵 하나만 건넬 수 있다.
- 정답은 맛과 굽기 상태의 조합으로 결정된다.
- 정답이 아니어도 만들어진 붕어빵 영혼은 영혼 도감에 등록된다.
- 실패한 손님은 일정 기간 뒤 다시 등장하며, 재도전할 때 단서를 하나 더 제공한다.
- 이야기를 해금한 손님은 특별 주문 후보에서 빠지지만 일반 손님으로 계속 등장한다.
- 8명의 이야기를 모두 해금해도 일반 영업과 도감 수집은 계속된다.

### 2.3 낮 대화 `말동무` 규칙

낮 영업 중 기다리고 있는 손님을 클릭하면 주문 처리와 별개로 짧게 말을 걸 수 있다. 이 대화는 손님의 성격과 특별 주문 사연을 미리 파악하는 탐색 수단이자, 이야기에 관심을 보인 플레이어에게 작은 운영 보상을 주는 기능이다.

> 8명 전체의 구현용 대화 대본은 [손님 8명 낮 대화 `말동무` 대본](./07_CUSTOMER_DAYTIME_TALK_DIALOGUE.md)을 기준으로 한다. 이 문서의 손님별 한 줄 문답보다 해당 대본을 우선한다.

- 손님마다 서로 다른 대화 주제 선택지 3개를 가진다.
- 한 번 말을 걸면 세 선택지 중 하나만 골라 답변을 듣고 대화를 종료한다.
- 같은 손님과는 게임 날짜 기준 하루에 한 번만 대화할 수 있다.
- 이미 들은 주제에는 도감과 선택지에 완료 표시를 붙이지만 다시 선택할 수 있다.
- 처음 듣는 주제를 완료하면 해당 내용이 손님 도감의 `들은 이야기`에 기록된다.
- 세 주제를 모두 들으면 그 손님의 성격과 사연을 파악한 것으로 처리하고 특별 주문 등장 조건 하나를 만족한다.
- 대화가 정상적으로 끝나면 해당 손님의 기다림·분노 게이지를 최대치의 10%p만큼 낮춘다. 이 수치는 플레이 테스트 후 조정할 수 있는 기획 기본값이다.
- 게이지는 0 아래로 내려가지 않으며, 하루 한 번 제한 때문에 같은 손님에게 감소 효과를 반복 적용할 수 없다.
- 대화 선택지가 나타난 순간부터 손님의 5초 답변이 끝날 때까지 게임 시간과 다른 손님의 기다림 게이지를 멈춘다.
- 대화 중에는 화면 전체를 어둡고 저채도로 보이게 덮어 다른 조리·손님 상호작용을 막고, 대화 중인 손님만 원래 색으로 강조한다.
- 선택하면 세 칸 대화 박스는 사라지고 손님의 답변을 강조된 손님 옆 말풍선에 5초간 표시한 뒤 현재 주문 말풍선으로 돌아간다.
- 완성된 붕어빵을 잡고 손님에게 드래그하는 중에는 전달 행동을 우선하며 대화창을 열지 않는다.
- 손님이 입장·퇴장 중이거나 이미 분노가 가득 차 떠나는 상태라면 대화할 수 없다.
- 그날 이미 대화한 손님에게는 말풍선 아이콘 대신 완료 표시를 보여 준다.

## 3. 무한 운영에서의 등장 구조

### 3.1 하루 흐름

```text
일반 영업
→ 마감 시간
→ 특별 손님 등장 여부 확인
→ 특별 주문 또는 바로 정산
→ 하루 정산
→ 상점·도감 확인
→ 다음 날 영업
```

### 3.2 특별 손님 후보 조건

다음 조건을 모두 만족한 손님만 그날의 특별 손님 후보가 된다.

1. 일반 손님으로 최소 3일 동안 등장해 낮 대화 주제 3개를 모두 완료했다.
2. 해당 손님의 정답 영혼에 필요한 맛이 상점에서 해금됐다.
3. 아직 손님 이야기가 해금되지 않았다.
4. 최근 특별 주문 실패 후 재등장 대기 기간이 끝났다.
5. 같은 날 다른 특별 손님이 선택되지 않았다.

### 3.3 추천 등장 규칙

- 첫 특별 주문은 시스템 학습을 위해 정현으로 고정한다.
- 첫 특별 주문은 정현의 낮 대화 주제 3개를 모두 들은 뒤 조건을 만족한 첫 마감에 발생시킨다. 정상 진행 기준으로 가장 빠른 시점은 3일차 마감이다.
- 이후에는 후보 중 `일반 방문 횟수가 많고 최근에 특별 손님으로 등장하지 않은 손님`을 우선한다.
- 정답 실패 시 2일 동안 쉬었다가 다시 후보가 된다.
- 재도전할 때는 기존 대사 뒤에 더 직접적인 힌트 한 줄을 추가한다.
- 후보가 없으면 특별 주문 없이 하루를 마감한다.
- 너무 오랫동안 이야기가 나오지 않는 상황을 막기 위해, 후보가 있을 때는 최소 3일 안에 특별 주문이 보장되게 한다.

## 4. 붕어빵 영혼 조합 규칙

### 4.1 맛은 영혼의 마음을 정한다

| 맛 | 영혼의 핵심 마음 | 성격 키워드 |
| --- | --- | --- |
| 팥 | 기본으로 돌아가기 | 소박함, 초심, 다시 시작 |
| 슈크림 | 자신의 즐거움 챙기기 | 자기 돌봄, 낙천, 여유 |
| 초코 | 놀이와 상상력 | 장난, 호기심, 몰입 |
| 크림치즈 | 감정을 부드럽게 표현하기 | 다정함, 솔직함, 포용 |
| 피자 | 원하는 것을 분명히 말하기 | 욕구, 표현, 자신감 |
| 민트 | 남과 다른 선택 받아들이기 | 개성, 변화, 엉뚱함 |
| 고구마 | 한곳에 머물며 관계 쌓기 | 뿌리, 인내, 안정 |
| 녹차 | 현재를 보고 새로 출발하기 | 맑음, 수용, 새 시작 |

### 4.2 굽기는 영혼의 행동 방식을 정한다

| 굽기 상태 | 행동 방식 | 성격 키워드 |
| --- | --- | --- |
| 말랑 | 서두르지 않고 유연하게 움직임 | 느긋함, 즉흥성, 부드러움 |
| 노릇 | 작은 행동을 꾸준히 이어 감 | 균형, 성실함, 지속성 |
| 바삭 | 망설이지 않고 행동하거나 말함 | 결단력, 직진, 선 긋기 |

`말랑`과 `바삭`은 조리 실패를 뜻하지 않는다. 특별 주문에서는 먹을 수 있는 굽기 범위를 세 구간으로 나눈다. 완전히 설익거나 탄 상태는 별도의 조리 실패로 처리하고 영혼을 만들지 않는다.

### 4.3 판정 결과

| 결과 | 조건 | 보상과 반응 |
| --- | --- | --- |
| 정확한 영혼 | 맛과 굽기 모두 일치 | 손님 이야기 컷, 손님 도감 전체 항목, 영혼 도감 등록 |
| 가까운 영혼 | 맛 또는 굽기 중 하나 일치 | 영혼 도감 등록, 손님의 짧은 반응과 추가 힌트 |
| 다른 영혼 | 둘 다 불일치 | 영혼 도감 등록, 일반 반응, 추후 재도전 |
| 조리 실패 | 설익음 또는 탐 | 영혼 미등장, 특별 손님의 위로 대사, 추후 재도전 |

## 6. 손님별 상세 기획

### 6.1 정현 — 일을 두고 가는 연습

#### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 나이·역할 | 32세, 중소기업 운영팀 회사원 |
| 기존 캐릭터 | 유지. 정장, 휴대폰, 메신저 가방을 사용한다. |
| 평소 선호 | 팥 붕어빵 |
| 겉성격 | 공손하고 성실하며 부탁받은 일을 빠르게 처리한다. |
| 숨은 고민 | 자신의 일이 아닌 부탁까지 거절하지 못해 퇴근 후의 시간이 계속 사라진다. |
| 필요한 태도 | 남은 일이 있어도 자기 시간을 선택하고 선을 긋는 태도 |

#### 평소 방문 대사

1. “팥 하나 주세요. 고르는 데 시간 쓰면 일이 더 밀려서요.”
2. “회사 단톡방은 퇴근 시간을 모르나 봐요.”
3. “제가 안 하면 아무도 안 할 것 같아서요.”

#### 낮 대화 선택지

상세 대사는 [낮 대화 대본의 정현 항목](./07_CUSTOMER_DAYTIME_TALK_DIALOGUE.md#2-정현--자기-몫의-시간을-남기지-못하는-회사원)을 사용한다. 주제는 `늦은 퇴근 / 계속 늘어나는 주문 / 울리는 전화`다.

#### 특별 주문 대사

> “오늘도 제 일이 아닌 것까지 다 끝냈는데…”  
> “이상하게 제 하루는 하나도 안 남았네요.”  
> “하… 일은 끝이 없네요. 붕어빵은 아무거나 하나 주세요.”

#### 정답 영혼

| 항목 | 내용 |
| --- | --- |
| 이름 | 칼퇴대장 크림붕 |
| 조합 | 슈크림 + 바삭 |
| 성격 | 자기 즐거움을 먼저 챙기며, 끝낼 시간을 스스로 선언한다. |
| 대표 대사 | “끝나지 않는 일은 두고 가면 돼. 넌 끝날 시간이 있잖아.” |
| 반대 관계 | 모든 일을 책임지려는 정현 ↔ 자기 시간을 당당하게 지키는 영혼 |

#### 성공 이야기 컷

1. 정현이 붕어빵을 베어 무는 순간 회사 단체 채팅 알림이 울린다.
2. 크림붕이 휴대폰 화면 위에 올라가 알림을 몸으로 덮는다.
3. 정현은 잠시 고민하다 휴대폰을 뒤집어 놓는다.
4. 다음 날, 정현이 정시에 회사를 나오며 “내일 해도 되는 일은 내일의 제가 하겠죠.”라고 말한다.

#### 가까운 정답 힌트

> “조금 마음이 가벼워졌어요. 그런데 아직도 퇴근한다고 말할 용기가 부족한 것 같네요.”

#### 해금 후 일반 대사

> “오늘은 알림을 끄고 먹으려고요.”

#### 평소 방문 대사

3. “콘티는 문제집 사이에 두면 아무도 안 봐요. 조금 구겨지는 게 문제지만요.”

#### 낮 대화 선택지

#### 성공 이야기 컷

#### 성공 이야기 컷

2. 현재, 태수는 딸이 붙여 둔 부품 이름표 덕분에 물건을 금방 찾고도 사과 문자를 다시 지운다.
3. 먼저말해 치즈붕이 휴대폰의 전송 버튼 옆에 앉고, 태수는 “그날은 내가 잘못 말했다. 도와줘서 고마웠다. 미안하다.”라고 보낸다.
4. “이번 주말에 갈게. 크림치즈 사 줘.”라는 답장이 오고, 태수는 팥과 크림치즈 붕어빵을 하나씩 주문한다.

#### 가까운 정답 힌트

> “말이 부드러워지는 건 알겠습니다. 결국 보내기 버튼은 제가 눌러야겠지요.”

#### 해금 후 일반 대사

> “오늘은 크림치즈도 하나 주십시오. 이번 주말에는 딸애가 옵니다.”

### 6.7 나리 — 마지막 주문을 정하고 퇴근하기

#### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 나이·역할 | 27세, 배달 플랫폼 라이더 |
| 외형 키워드 | 반사띠 재킷, 헬멧, 휴대폰 거치대, 보온 배달 가방 |
| 평소 선호 | 민트 붕어빵 |
| 겉성격 | 활기차고 속도가 빠르며, 바쁜 날에도 “이 정도는 금방 끝낸다”고 말한다. |
| 숨은 고민 | 수입이 일정하지 않아 배달 앱의 주간 보너스 목표를 놓치지 않으려 한다. 필요한 목표를 채운 뒤에도 앱이 제안하는 다음 보상과 스스로 정한 숫자를 따라 `한 건만 더`를 반복하며 식사와 동료 약속을 계속 미룬다. |
| 필요한 태도 | 수입 문제를 가볍게 여기지 않으면서도, 정해 둔 종료 시간과 작은 약속 하나를 꾸준히 지키는 태도 |

#### 평소 방문 대사

1. “민트 하나만 주세요. 다음 주문 가면서 먹을게요.”
2. “이번 주 보너스까지 세 건만 더 하면 돼요.”
3. “저녁 약속이요? 금방 끝내고 가려고 했는데 또 늦었네요.”

#### 낮 대화 선택지

상세 대사는 [낮 대화 대본의 나리 항목](./07_CUSTOMER_DAYTIME_TALK_DIALOGUE.md#8-나리--한-건만-더-때문에-퇴근하지-못하는-배달-라이더)을 사용한다. 주제는 `붕어빵으로 때우는 저녁 / 껐다가 다시 켜는 배달 앱 / 늦어 버린 저녁 약속`이다.

#### 특별 주문 대사

> “오늘은 동료들이랑 저녁 먹기로 했는데, 보너스까지 한 건 남아서 또 취소했어요.”
> “그 한 건을 끝내고 보니 식당도 닫았네요. 이상하게 매일 마지막 주문이 하나씩 더 생겨요.”
> “빨리 먹고 갈 수 있는 걸로 하나 주세요.”

#### 정답 영혼

| 항목 | 내용 |
| --- | --- |
| 이름 | 저녁지킴 고구붕 |
| 조합 | 고구마 + 노릇 |
| 성격 | 정해 둔 종료 시간을 지키고, 오늘 한 약속은 다음 목표보다 먼저 챙긴다. |
| 대표 대사 | “한 건 더는 내일도 있어. 오늘 약속은 오늘뿐이야.” |
| 반대 관계 | 목표 숫자 때문에 끝없이 일을 연장하는 나리 ↔ 정해 둔 시간에 멈추고 약속을 지키는 영혼 |

#### 성공 이야기 컷

1. 다음 주, 나리는 약속 시간 전에 필요한 주간 목표를 채운다. 앱에는 곧바로 `3건 더 하면 추가 보상`이라는 새 안내가 뜬다.
2. 저녁지킴 고구붕이 휴대폰 시계의 약속 시간 옆에 앉고, 나리는 추가 목표를 시작하지 않은 채 배달 앱을 오프라인으로 바꾼다.
3. 나리는 “오늘은 갈게요.”라고 답하고 처음으로 약속 시간에 맞춰 동료들이 있는 식당에 도착한다.
4. 식사를 마친 뒤 다음 주 같은 요일의 저녁 약속을 달력에 저장하고, 그날의 종료 시간을 한 시간 앞당겨 둔다.

#### 가까운 정답 힌트

> “오늘은 멈출 수 있을 것 같아요. 다음 약속 때도 같은 시간에 앱을 끌 수 있어야겠죠.”

#### 해금 후 일반 대사

> “오늘은 두 개 포장해 주세요. 동료들이랑 나눠 먹고 퇴근하려고요.”

### 6.8 준호 — 축하와 질투를 함께 인정하기

#### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 나이·역할 | 24세, 부상으로 은퇴한 전직 스피드 스케이팅 선수 |
| 외형 키워드 | 운동 재킷, 무릎 보호대, 오래된 팀 열쇠고리, 반듯한 자세 |
| 평소 선호 | 슈크림 붕어빵 |
| 겉성격 | 말수가 적고 무심해 보인다. 스케이팅 이야기가 나오면 대답을 짧게 끊는다. |
| 숨은 고민 | 어릴 때부터 함께 훈련한 가장 가까운 친구가 준호의 부상 이후에도 선수 생활을 이어 가 국가대표가 됐다. 친구가 잘된 것은 기쁘지만 자신이 원했던 자리라는 질투도 들어, 그런 자신을 나쁜 친구라고 생각하며 연락을 피한다. |
| 필요한 태도 | 기쁨과 질투가 동시에 존재할 수 있음을 받아들이고, 감정을 정리한 척하지 않은 채 친구에게 솔직하게 말하는 태도 |

#### 평소 방문 대사

1. “경기 결과만 봤어요. 영상은 안 봤고요.”
2. “오늘은 좀 걷다 왔습니다.”
3. “전화는 나중에 받으려고요.”

#### 낮 대화 선택지

상세 대사는 [낮 대화 대본의 준호 항목](./07_CUSTOMER_DAYTIME_TALK_DIALOGUE.md#9-준호--친구의-기쁜-소식을-피하는-전직-선수)을 사용한다. 주제는 `경기 결과 / 평소보다 늦은 방문 / 받지 않는 전화`다.

#### 특별 주문 대사

> “팥 하나 주세요.”
> “오늘은 축하 전화를 해야 하는데…… 자꾸 미루게 되네요.”
> “바삭한 것보다 좀 부드러운 걸로 부탁할게요.”

특별 주문에서는 상대가 누구인지, 무엇을 축하해야 하는지 밝히지 않는다. 정답 붕어빵을 건넨 뒤 재생되는 컷씬에서 친구와 국가대표 선발 이야기를 공개한다.

#### 정답 영혼

| 항목 | 내용 |
| --- | --- |
| 이름 | 두마음 팥붕 |
| 조합 | 팥 + 말랑 |
| 성격 | 서로 반대되는 감정을 억지로 하나만 고르지 않고 둘 다 솔직하게 말한다. |
| 대표 대사 | “둘 다 말하면 되잖아. 축하한다고. 부럽다고.” |
| 반대 관계 | 질투를 느낀 자신을 나쁜 친구라고 단정하는 준호 ↔ 상반된 감정을 그대로 인정하는 영혼 |

#### 성공 이야기 컷

상세한 `장면 5개 + 해금 일러스트 1개` 구성은 [준호 컷씬 기획 문서](./cutscenes/08_JUNHO.md)를 따른다. 특별 주문에서 숨긴 친구의 정체와 국가대표 선발 사실을 컷씬 안에서 순서대로 공개한다.

#### 가까운 정답 힌트

> “조금 낫네요. 그래도 지금 전화가 오면 또 안 받을 것 같습니다.”

#### 해금 후 일반 대사

> “팥 두 개 주세요. 한 명 더 올 겁니다.”

## 7. 도감 구성

### 7.1 손님 도감

이야기 진행에 따라 같은 항목을 단계적으로 공개한다.

| 상태 | 공개 내용 |
| --- | --- |
| 만나지 않음 | 손님 실루엣과 물음표 |
| 일반 방문 | 이름, 외형, 평소 선호 맛, 들은 평소 대사 |
| 특별 주문 실패 | 특별 주문 단서, 시도한 영혼, 다음 힌트 |
| 이야기 해금 | 전체 소개, 이야기 컷, 정답 영혼, 해금 후 대사 |

### 7.2 붕어빵 영혼 도감

- 영혼 이름
- 맛과 굽기 상태
- 마음 키워드 1개와 행동 키워드 1개
- 대표 대사
- 처음 만들어진 날짜
- 연결된 손님이 밝혀졌다면 해당 손님 아이콘
- 아직 만들지 않은 조합은 실루엣

8가지 맛과 3가지 유효 굽기 상태를 사용하면 최대 24종의 영혼 조합이 생긴다. 8명의 정답 영혼은 고유 이름과 대표 대사를 갖고, 나머지 조합은 공통 명명 규칙과 짧은 성격 설명을 사용해 제작량을 줄인다.

## 8. 제작 범위 관리

손님 8명을 일주일 안에 구현하려면 모든 이야기를 서로 다른 고급 컷신으로 제작하면 안 된다.

### 권장 재사용 구조

- 특별 주문 대화 패널 1종을 모든 손님이 공유한다.
- 화면 왼쪽의 전용 3단 선택지 대화 박스와 손님 답변 말풍선, `대화 가능 / 오늘 대화 완료` 아이콘을 모든 손님이 공유한다.
- 이야기 컷은 손님당 3~4컷으로 제한한다.
- 배경은 회사, 학교, 집·동네, 가게의 공통 배경을 재사용한다.
- 손님 기본 표정은 `평상 / 기쁨 / 실망` 3종을 공통 규격으로 맞춘다.
- 영혼은 공통 몸체에 맛별 색상과 장식, 굽기별 표정을 조합한다.
- 정답 영혼 8종만 고유 이름표·소품·등장 효과를 추가한다.
- 대사는 한 화면에 최대 2문장만 보여 준다.

### 이야기 다양성 확인표

| 구분 | 포함된 이야기 |
| --- | --- |
| 연령 | 어린이, 청소년, 청년, 중년, 노년 |
| 생활 영역 | 학교, 회사, 가족, 일, 스포츠, 동네 공동체 |
| 고민 유형 | 경계 설정, 진로, 취향, 애도, 놀이, 사과, 관계, 정체성 |
| 성공 행동 | 퇴근, 체험 신청, 취향 표현, 새 작업 시작, 도움 요청, 사과, 머무르기, 초보 도전 |

## 9. 구현용 콘텐츠 데이터 항목

각 손님 데이터를 다음 항목으로 저장할 수 있어야 한다.

```text

ageAndRole
```

게임 전체 저장 데이터에는 다음 진행 상태가 필요하다.


`talkedCustomerIdsToday`는 새 영업일을 시작할 때 비운다. 낮 영업 중 저장하고 다시 접속하는 경우에는 같은 날 대화 보상을 반복해서 받지 못하도록 현재 목록을 저장 데이터에 포함한다.

## 10. 아직 확정하지 않은 항목
