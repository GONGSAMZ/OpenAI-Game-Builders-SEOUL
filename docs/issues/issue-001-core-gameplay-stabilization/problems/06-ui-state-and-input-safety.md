# P2-06 — UI 전환과 선택 도구가 없는 상태의 안전성 문제

## 한 줄 설명

게임 UI를 설정 화면으로 바꿨다가 돌아오면 주문 화면이 즉시 복원되지 않을 수 있고, 선택 도구가 없는 상태에서 조리 오브젝트를 누르면 예외가 발생할 가능성이 있다. UI 관리 함수도 닫을 대상이 없을 때를 방어하지 않는다.

## 현재 상태

- 코드 확인: 완료
- Unity Editor 재현: 필요
- WebGL 재현: 필요
- 우선순위: `P2`
- 주요 파일: `Assets/Scripts/UI/UI_Scene/UI_Game.cs`, `Assets/Scripts/UI/UI_Settings.cs`, `Assets/Scripts/Managers/UIManager.cs`, `Assets/Scripts/UI/UI_Base.cs`, `Assets/Scripts/Controllers/FishBunController.cs`

## 이슈 #1에서 다루는 범위

이번 작업에서는 UI를 새로 디자인하지 않는다. 다음처럼 핵심 플레이를 멈추거나 정보를 잃게 만드는 안정성 문제만 다룬다.

- 설정 화면 복귀 뒤 진행 중 주문 정보가 보이지 않음
- 선택 도구가 없을 때 조리 클릭으로 예외 발생
- 닫을 UI가 없는데 `CloseUI()`가 호출되어 예외 발생
- UI 바인딩 배열 크기가 실제 항목 수와 달라 생기는 빈 참조 위험

화면 해상도, 배치, 키보드 단축키, 드래그 조작 개선은 이슈 #4로 넘긴다.

## 코드에서 확인한 위험

1. `UI_Game.Init()`은 주문 갱신 이벤트를 연결하지만 현재 주문을 즉시 그리지 않는다. 설정 화면에서 돌아와 새 `UI_Game`을 만들면 다음 주문 변경 전까지 전체 주문 패널이 비어 있을 수 있다.
2. `FishBunController.addFilling()`과 `addBatter()`는 `ToolController.selectedTool`이 `null`인지 확인하기 전에 태그를 읽는다.
3. `UIManager.CloseUI()`는 씬 UI가 없는 경우와 팝업 스택이 빈 경우를 검사하지 않는다.
4. `UI_Base.Bind<T>()`의 배열 크기는 열거형 이름 배열이 아니라 컴포넌트의 `name.Length`를 사용한다. 현재는 우연히 필요한 수보다 크게 잡힐 수 있지만, UI 이름이 짧아지면 인덱스 오류 위험이 있다.

## 재현 절차

### 주문 UI 복원

1. 손님의 주문을 접수한다.
2. 설정 버튼을 누른다.
3. 돌아가기 버튼을 누른다.
4. 상단 또는 전체 주문 패널이 현재 주문을 즉시 표시하는지 확인한다.

### 선택 도구 없음

1. 다음 날 전환 또는 초기화 직후 선택된 도구가 없는 상태를 만든다.
2. 남아 있는 조리 오브젝트를 누르거나 가능한 입력 순서를 반복한다.
3. 콘솔 예외를 확인한다.

### 빈 UI 닫기

1. 씬 시작·전환과 팝업 자동 닫힘을 반복한다.
2. 닫기 동작이 빠르게 중복되어도 예외가 없는지 확인한다.

## 수정 방향

1. `UI_Game.Init()` 마지막에 현재 `Managers.Game.Order`를 사용해 주문 패널을 즉시 갱신한다.
2. 조리 단계 함수 시작 시 `selectedTool == null`이면 아무 상태도 바꾸지 않고 반환한다.
3. `UIManager.CloseUI()`에서 씬 UI의 존재와 팝업 스택 개수를 확인한다.
4. `UI_Base.Bind<T>()` 배열 크기를 `names.Length`로 고친다.
5. UI가 파괴될 때 더 이상 필요한 이벤트가 아니면 구독을 해제한다. 정적 이벤트를 유지한다면 중복 구독과 파괴된 대상 접근이 없는지 확인한다.
6. 방어 반환이 실행될 때 돈, 비용, 조리 상태, 주문 상태가 바뀌지 않게 한다.

## 완료 조건

- [ ] 설정 화면에서 돌아오자마자 기존 주문 정보가 표시된다.
- [ ] 선택 도구가 없는 상태에서 클릭해도 예외와 상태 변경이 없다.
- [ ] UI 닫기 요청이 중복되어도 빈 스택 예외가 없다.
- [ ] 모든 UI 바인딩 배열 크기가 열거형 항목 수와 일치한다.
- [ ] 설정 화면을 10회 왕복해도 버튼 동작이 중복 실행되지 않는다.
- [ ] UI 왕복 중 돈, 시간, 주문 수량이 임의로 초기화되지 않는다.
