# 08 준호 — 축하한다고 말하기까지

| 항목 | 내용 |
| --- | --- |
| 손님 | 준호, 24세 전직 스피드 스케이팅 선수 |
| 이야기 주제 | 가까운 친구의 성공을 기뻐하면서도 질투하는 자신을 받아들이기 |
| 정답 영혼 | 두마음 팥붕 |
| 정답 조합 | 팥 + 말랑 |
| 컷씬 길이 | 클릭 장면 5개 + 해금 일러스트 1개 |
| 핵심 변화 | 감정을 다 정리한 척하지 않고 친구에게 축하와 솔직한 속마음을 함께 말한다. |

## 특별 주문 진입

마감 직전, 준호가 진동하는 휴대폰을 손에 쥔 채 들어온다. 화면에 뜬 이름을 확인하지만 전화를 받지 않고 휴대폰을 뒤집어 놓는다.

> “팥 하나 주세요.”  
> “오늘은 축하 전화를 해야 하는데…… 자꾸 미루게 되네요.”  
> “바삭한 것보다 좀 부드러운 걸로 부탁할게요.”

이 대화에서는 상대가 누구인지, 무엇을 축하해야 하는지 설명하지 않는다. 낮 대화에서 본 `경기 결과`, `받지 않는 전화`, `집에 가지 않고 걷는 행동`만 다시 연결한다.

정답 붕어빵을 건네면 준호가 한입 베어 문다. 휴대폰이 다시 진동하고, 준호가 화면을 바라보는 순간 장면 1로 전환한다.

## 장면 1 — 반으로 나눠 먹던 날

**목적:** 전화의 상대가 단순한 경쟁자가 아니라 준호와 가장 가까웠던 친구임을 처음 밝힌다.

**화면 구성:** 어린 시절 빙상장 밖의 3칸. 훈련 종료 / 붕어빵 봉투 / 반으로 나눈 팥붕.

1. 어린 준호와 친구가 마지막까지 링크를 돌고 함께 빙상장 밖으로 나온다.
2. 친구가 붕어빵 하나를 사지만 주머니를 뒤져도 동전이 더 나오지 않는다.
3. 둘은 팥붕을 반으로 갈라 나눠 먹으며 다음 경기에서는 누가 이길지 티격태격한다.

**친구:** “다음에는 내가 먼저 들어온다.”

**준호:** “그 말 지난번에도 했어.”

**캡션:** “둘은 오래도록 같은 출발선에 섰고, 경기 뒤에는 늘 같은 것을 나눠 먹었다.”

## 장면 2 — 한 사람만 남은 링크

**목적:** 준호가 친구의 성공을 힘들어하는 이유가 단순한 경쟁심이 아니라, 함께 가던 시간이 끊어진 상실감임을 보여 준다.

**화면 구성:** 부상 이후의 4칸. 빈 자리 / 재활 운동 / 친구의 훈련 / 국가대표 선발 알림과 걸려 오는 전화.

1. 준호의 부상 뒤, 링크 옆 벤치에는 준호의 자리가 비어 있다.
2. 준호는 재활 운동을 하며 친구가 보내 온 훈련 사진을 확인한다.
3. 친구는 계속 선수 생활을 이어 가고, 준호는 관중석에서 잠시 보다가 경기장을 먼저 나온다.
4. 시간이 흐른 뒤 휴대폰에 친구의 국가대표 선발 알림이 뜬다. 곧바로 친구에게 전화가 오지만 준호는 받지 못한다.

**휴대폰 알림:** “스피드 스케이팅 국가대표 선발”

**친구의 메시지:** “됐다. 끝나고 전화할게.”

**캡션:** “친구가 앞으로 갈수록 준호는 기뻤고, 같은 만큼 자신이 멈춘 자리도 선명해졌다.”

## 장면 3 — 두 마음이 나온 붕어빵

**목적:** 정답 영혼이 준호의 감정을 없애지 않고, 서로 반대되는 두 감정이 함께 있을 수 있음을 보여 준다.

**화면 구성:** 현재 붕어빵 가게의 4칸. 말랑한 팥붕 / 영혼 등장 / 두 표정 / 통화 버튼.

1. 준호가 말랑한 팥붕을 가르자 팥 사이에서 두마음 팥붕이 얼굴을 내민다.
2. 영혼의 한쪽은 작은 축하 깃발을 들고 웃고, 다른 한쪽은 메달을 보지 못한 척 고개를 돌린다.
3. 준호가 두 표정을 번갈아 보다가 작게 웃는다.
4. 휴대폰에 같은 친구의 전화가 다시 온다. 준호의 손가락이 통화 버튼 위에서 멈춘다.

**두마음 팥붕:** “축하하는 마음도 네 거고, 보기 싫은 마음도 네 거야.”

**준호:** “둘 다 있다고 말해도 되나…….”

**두마음 팥붕:** “하나만 진짜인 척하는 것보다는 낫지.”

## 장면 4 — 늦게 받은 전화

**목적:** 준호가 멋진 축하 인사를 준비하는 대신, 정리되지 않은 감정을 친구에게 직접 말하게 한다.

**화면 구성:** 가게 앞의 긴 칸과 통화 장면 3칸. 전화 받기 / 짧은 침묵 / 솔직한 말 / 친구의 답.

1. 준호가 가게 밖으로 나와 전화를 받는다.
2. 친구가 먼저 말을 건다.
3. 준호는 몇 번 입을 떼려다 짧게 축하를 전한다.
4. 잠시 후, 아직 친구의 경기 영상을 볼 수 없다는 말도 덧붙인다.

**친구:** “너 전화 진짜 안 받더라.”

**준호:** “미안. 그리고…… 축하한다.”

**준호:** “근데 나 아직 네 경기는 못 보겠어.”

**친구:** “응. 안 봐도 돼. 전화만 좀 받아.”

친구는 준호에게 당장 괜찮아지라고 하거나 질투를 이해한다고 길게 설명하지 않는다. 두 사람이 원래 하던 말투로 짧게 대화를 끝낸다.

## 장면 5 — 다시 반으로

**목적:** 갈등이 완전히 사라지지는 않았지만, 준호가 친구와의 관계를 피하지 않게 된 작은 변화를 보여 준다.

**화면 구성:** 며칠 뒤 가게 앞의 4칸. 친구의 방문 / 팥붕 두 개 / 경기 이야기 앞의 머뭇거림 / 나란히 먹는 두 사람.

1. 훈련을 마치고 동네에 들른 친구가 가게 앞에서 준호를 기다린다.
2. 준호가 팥붕 두 개를 받아 하나를 친구에게 건넨다.
3. 친구가 다음 경기를 이야기하려다 준호의 표정을 보고 말을 멈춘다.
4. 준호가 먼저 `결과는 알려 줘`라고 말하고, 둘은 가게 앞에서 붕어빵을 먹는다.

**준호:** “영상은 좀 나중에 볼게. 그래도 결과는 알려 줘.”

**친구:** “그건 원래 네가 제일 먼저 물어봤잖아.”

**캡션:** “준호는 아직 링크를 오래 바라보지 못했다. 그래도 친구의 전화를 피하지는 않았다.”

## 해금 일러스트 — 두 마음으로 건넨 축하

- 준호가 말랑한 팥 붕어빵을 들고 작게 웃는다.
- 준호 옆에는 친구가 서 있지만 주인공처럼 크게 강조하지 않고, 두 사람이 다시 같은 자리에 섰다는 관계만 보이게 한다.
- 두마음 팥붕은 두 사람 뒤에서 한 손에는 작은 축하 깃발, 다른 손에는 접힌 경기표를 들고 있다.
- 붕어혼은 상반된 표정이나 좌우 색 차이를 가지되 하나의 팥붕 실루엣 안에서 이어진다.
- 배경에는 어린 시절 둘이 팥붕을 반으로 나누던 장면이 따뜻한 잔상처럼 겹친다.
- 화면 문구:
  - `준호의 이야기 해금`
  - `축하한다고 말하기까지`
  - `두마음 팥붕 · 팥 + 말랑`
  - 준호: “아직 다 보진 못해도, 네 소식은 들을게.”

## 해금 후 일반 방문 대사

> “팥 두 개 주세요. 한 명 더 올 겁니다.”

## 제작 시 유지할 단서

- 특별 주문 대사에서는 친구, 국가대표, 질투를 직접 밝히지 않는다. 이 정보는 장면 1~2에서 차례로 공개한다.
- 운동 재킷, 무릎 보호대, 오래된 팀 열쇠고리를 반복해 준호의 과거와 현재를 연결한다.
- 친구를 준호의 자리를 빼앗은 인물이나 준호를 완벽히 이해하는 상담자처럼 묘사하지 않는다.
- 준호의 질투가 사라졌다고 결론 내리지 않는다. 연락을 받고 결과를 묻는 행동이 이번 이야기의 변화다.
- 장면 1의 반쪽 팥붕과 장면 5의 팥붕 두 개를 대비해 두 사람의 관계 변화를 보여 준다.
- 이미지 안에는 대사와 캡션을 넣지 않고 Unity UI로 분리한다.
